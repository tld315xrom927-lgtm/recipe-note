# Recipe Note — わたしのレシピノート

淡色ベージュの和風デザインの、個人用レシピノートWebアプリです。
API・有料サービス・ログインは使っていません。データはすべて端末のブラウザ内（IndexedDB）に保存されます。

## 開くURL（iPhone・iPad・PC 共通）
**https://tld315xrom927-lgtm.github.io/recipe-note/**

PCを起動していなくても使えます。iPhone・iPad は Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます（オフラインでも開けます）。
レシピ・写真・献立は Supabase に保存され、合言葉を入れた端末どうしで自動的に同期されます。

### 公開について
- GitHub（公開リポジトリ）にはアプリ本体と初期サンプルだけを置いています
- スクショから取り込んだレシピ・料理写真・元画像は GitHub には置かず、合言葉で守られた Supabase にだけ保存しています（PC の `js/added-recipes*.js`・`assets/recipes/`・`assets/sources/` に元ファイルがあります）
- アプリを更新して公開するときは `git commit` のあと `python tools/publish.py "更新内容"`（公開しないファイルが混ざっていないか確認してから送ります）

### PCから配信する方法（従来どおり・予備）
`start.bat` をダブルクリックすると `http://localhost:8080/` でも開けます。スクショ由来のレシピの写真をクラウドへ移すときは、この方法で一度開いて同期してください（自動で写真をクラウドに保存します）。

## クラウド同期（Supabase・無料プラン）
Supabase を「正本」として、iPhone・iPad・PC のどれで追加・編集・削除・お気に入り・献立を変えても全端末に反映されます。
端末内のデータは表示を速くするための写しで、開くたびにクラウドの最新にそろえます（端末のデータが消えてもクラウドから元どおりになります）。

### 最初の1回だけ（Supabase の準備）
1. https://supabase.com で無料アカウントを作り、「New project」でプロジェクトを作成（Free プラン）
2. 左メニュー「SQL Editor」→ このフォルダの `supabase/setup.sql` の中身を全部貼り付けて「Run」
   （更新版の setup.sql が出たときも同じ操作。何度実行してもデータは消えません）
3. 画面上部の「Connect」（または「Project Settings」→「Data API」）で **Project URL**、「Project Settings」→「API Keys」で **Publishable key** をコピー（余分な文字が付いていてもアプリ側で取り除きます）

### うまくいかないとき
- 「同期設定」→「接続診断をする」で、どこで止まっているか（URL・キー・setup.sql・合言葉・未送信）が1つずつ表示されます。「結果をコピー」で内容を共有できます（合言葉は含まれません）
- 一覧画面の上に「この端末はクラウドに接続されていません」と出ている端末は、変更がほかの端末に届きません

### 各端末で
1. PC：一覧画面のいちばん下「同期設定」で Project URL・Publishable key・合言葉（8文字以上）を入れて「接続して同期をはじめる」
2. iPhone・iPad：PCの同期設定に出る **QRコードをカメラで読み取る** → URLとキーが入った画面が開くので、同じ合言葉を入れて接続
3. 各端末の同期設定で「クラウド ◯件 ／ この端末 ◯件　一致」と出ていればOK

### 反映のタイミング
- 変更はすぐにクラウドへ送信（つながらないときは「未送信」として残し、つながったら自動で送信）
- ほかの端末へは Supabase Realtime の通知ですぐ反映。通知が使えない環境でも、開いている画面は10秒ごと・アプリに戻ったとき・再読み込み時にクラウドと照合します

### 注意
- `js/cloud-config.js` に URL とキーを書いておくと、各端末では合言葉を入れるだけで済みます
- データは合言葉で守られます（テーブルは直接読めず、合言葉を確認する関数経由でだけ読み書きします）
- secret key（service_role key）はアプリに入力しないでください
- 同じレシピを2台で同時に変えた場合は、あとから変更したほうが残ります
- 合言葉を忘れたときは `setup.sql` の最後にある1行を SQL Editor で実行し、もう一度設定してください（データは残ります）
- PCで配信している間（start.bat）は、iPhone・iPad は PC と同じWi-Fiで `http://192.168.…:8080` を開きます

## 献立
- 一覧画面の右上「献立」（スマホではカレンダーのアイコン）から開きます
- 今日から7日分（「さらに7日分を表示」で延長）を日付ごとに表示し、料理名と写真が並びます。料理をタップするとレシピ詳細が開きます
- 「料理を追加」で全レシピから選択（検索・カテゴリで絞り込み、複数選択可）。1日に何品でも登録できます
- 入れ替えボタンで別の料理に変更、×で献立から外す、「この日をすべて消す」で1日分を削除（レシピ自体は消えません）
- 上の日付欄から好きな日付の献立を作れます。レシピ詳細の「献立に追加」からも登録できます
- 過去の献立は下の「過去の献立」にまとまります

## 画面
| 画面 | 内容 |
|---|---|
| 表紙 | 「Recipe Note」＋「レシピをひらく」 |
| レシピ一覧 | 写真付きカード / 検索（料理名・材料・メモ）/ お気に入り絞り込み / カテゴリ絞り込み |
| レシピ詳細 | 料理名・写真・カテゴリ・調理時間・材料と分量・番号付きの作り方・メモ |
| 追加・編集 | 料理名・カテゴリ・調理時間・材料・作り方・メモ・写真の登録、削除 |

元画像：
- スクショから取り込んだレシピは、詳細画面の下に「元画像」として元のスクショが表示されます（タップで拡大、前へ／次へで切り替え）

カテゴリの管理：
- 一覧画面のカテゴリ列の右端「編集」から、カテゴリ管理画面を開けます
- カテゴリの追加・名前の変更・削除・並び替え（↑↓）ができます。一覧のカテゴリもこの順番で並びます
- 名前を変えると、そのカテゴリのレシピもまとめて新しい名前になります
- カテゴリを削除しても、レシピは削除されず「未分類」へ移動します
- レシピの追加・編集画面では「＋新しいカテゴリ」から、その場でカテゴリを作れます
- AIレシピ貼り付けで一覧にないカテゴリ名を読み取った場合は「新規」として表示され、保存時にカテゴリへ追加されます

料理中に便利な機能（詳細画面）：
- 材料・手順をタップするとチェック（済んだものが薄くなる）
- 「文字」ボタンで文字サイズを 標準 → 大 → 特大 に切り替え
- 「画面ON」で料理中に画面が自動で消えないようにする（対応端末のみ）

## AIレシピ貼り付け
追加・編集画面の「AIレシピ貼り付け」から使います。

1. 「ChatGPT用の依頼文をコピー」→ ChatGPTに貼り付け、整理したいレシピを添えて送信
2. ChatGPTの回答をコピーして貼り付け欄へ
3. 「読み込んで入力」で各項目に自動で振り分け → 内容を確認して保存

形式：
```
【料理名】ダルゴナコーヒー
【カテゴリ】ドリンク
【調理時間】5分
【分量】1人分
【材料】
・インスタントコーヒー：大さじ2
・白砂糖：大さじ2
【作り方】
1. ボウルにインスタントコーヒーと白砂糖を入れる。
2. お湯を少しずつ加えながら泡立てる。
【メモ】
・牛乳は豆乳でも美味しい。
```
`料理名：〇〇` や `## 材料（2人分）` のような書き方、`①` `STEP1` などの番号、`じゃがいも　3個` のような空白区切りにも対応しています。
カテゴリは「ご飯・麺→主食」「おかず→主菜」「サラダ→副菜」「汁物→スープ」「デザート→おやつ」「飲み物→ドリンク」のように近い言葉からも判定します。
